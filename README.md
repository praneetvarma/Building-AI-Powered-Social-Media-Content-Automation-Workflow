# AI-Powered Social Media Content Automation Workflow

An LLM-powered automation workflow built using n8n to streamline social media content creation and publishing.

## Features

* Generates engaging social media content using AI.
* Refines and optimizes posts through prompt engineering.
* Automates content workflows with minimal manual intervention.
* Integrates external services and APIs for seamless execution.

## Tech Stack

* n8n
* Google Gemini
* Prompt Engineering
* API Integrations

## Setup

1. Import the workflow JSON into n8n.
2. Configure the required API credentials.
3. Activate the workflow to automate content generation and publishing.
